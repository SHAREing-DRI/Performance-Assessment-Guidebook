\chapter{Preparation}
\label{chapter:preparation}

In this chapter, we discuss various steps that we might want to do \emph{before} we dive into any benchmarking or assessment.
It summarises activities that ensure that we are well-prepared to run assessments, but it also comprises steps that ensure that we understand the code sufficiently to come up with unbiased and valid statements.
